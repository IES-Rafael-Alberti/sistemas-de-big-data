# UD6 — Proyecto integrador

Esta unidad organiza el proyecto final. El producto esperado es un sistema de datos reproducible que conecte ingesta, calidad, procesamiento, visualización y documentación técnica.

## Ruta de trabajo

| Fase | Qué hacer | Evidencia mínima |
| ---- | -------- | ---------------- |
| 0. Tema y alcance | Lee el [guion del proyecto](../ud06-proyecto/guion_proyecto.md), elige dominio y fuentes | Problema, equipo, 2+ fuentes y primer boceto Medallion. |
| 1. Arquitectura e ingesta | Diseña Bronze/Silver/Gold y crea ingesta reproducible | Script de ingesta, Bronze en Parquet y reporte inicial. |
| 2. Calidad y procesamiento | Construye Silver/Gold y aplica calidad/RGPD | Dataset Gold, linaje, checklist y métricas antes/después. |
| 3. Dashboard técnico | Crea dashboard técnico de pipeline | Visualizaciones de caudal, calidad, rendimiento y estado. |
| 4. Cierre | Prepara memoria, defensa y declaración de IA | Repositorio reproducible, memoria y presentación. |

## Criterio SBD/BDA/PIA

- **SBD** evalúa arquitectura, pipeline, calidad, almacenamiento, procesamiento, dashboard técnico, coste y reproducibilidad.
- **Big Data Aplicado** puede evaluar dashboard de negocio, interpretación, cliente y toma de decisiones.
- **Programación de IA** puede evaluar modelos, predicciones o componentes de IA si el proyecto los incluye.

## Después de esta unidad

Deberías poder defender un proyecto técnico de datos: arquitectura, decisiones, costes, calidad, limitaciones y resultados.
