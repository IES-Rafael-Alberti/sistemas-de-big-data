# UD4 — BI y orquestación

Esta unidad conecta los datos procesados con visualización, cuadros de mando y automatización de pipelines. La idea central es pasar de “tengo datos” a “tengo un proceso que produce información útil”.

## Ruta de trabajo

La ruta principal de SBD no es “hacer gráficos bonitos”. Es entender cómo un sistema produce datos fiables para un dashboard técnico y cómo se automatiza ese flujo.

## Criterio SBD/BDA en esta unidad

En **Sistemas de Big Data** el foco es técnico: seleccionar herramientas, preparar el modelo, construir dashboards de seguimiento y orquestar pipelines reproducibles.

Cuando el foco sea cliente final, estrategia comercial, interpretación de negocio o toma de decisiones empresariales, el material se puede reutilizar en **Big Data Aplicado**.

## Después de esta unidad

Deberías poder construir un dashboard técnico, distinguir BI descriptivo de analítica predictiva y explicar por qué un pipeline necesita orquestación.
