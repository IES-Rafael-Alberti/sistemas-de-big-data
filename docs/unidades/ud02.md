# UD2 — Almacenamiento e ingesta

Esta unidad trabaja la entrada de datos en sistemas Big Data: fuentes, formatos, almacenamiento, calidad incremental y primeras decisiones de seguridad.

No empieces por la práctica grande. La unidad está pensada como una progresión:

## Criterio SBD/BDA en esta unidad

En **Sistemas de Big Data** el foco de UD2 es técnico: ingesta, almacenamiento, formatos, calidad, seguridad, reproducibilidad y coste del sistema. Las prácticas cloud o con herramientas visuales pueden servir como ampliación, pero la ruta principal debe poder realizarse con herramientas locales y reproducibles.

Si un caso se orienta a cliente final, BI de negocio o solución completa de empresa, se puede reutilizar en **Big Data Aplicado**, pero no debe desplazar el objetivo principal de UD2.

## Después de esta unidad

Deberías poder diseñar una ingesta reproducible, elegir formato de almacenamiento, justificar el coste de una solución y detectar riesgos básicos de calidad y privacidad.
