# UD6 — Teoría del Proyecto Integrador

En este proyecto final e integrador, el material teórico es transversal y se encuentra consolidado en el **guión oficial del proyecto** situado en la raíz de esta unidad:

- `../guion_proyecto.md`

### Contenido Teórico Aplicado
En el guión se especifican:
1. **Filosofía del proyecto**: enfoque de sistemas Big Data (fuentes → ingesta → almacenamiento → calidad → procesamiento → consulta/visualización).
2. **Uso permitido de IA Generativa**: documentación del proceso de apoyo (herramientas, prompts, verificaciones, etc.).
3. **Criterios de Arquitectura**: justificación del diseño Medallion y selección de tecnologías.
4. **Coordinación multi-módulo**: interacción y límites con los módulos de *Big Data Aplicado* (BI de negocio) y *Programación de la IA* (modelos de ML).

El alumnado debe aplicar los conocimientos adquiridos a lo largo de las unidades 1 a 5 para fundamentar todas las decisiones técnicas tomadas en su memoria de proyecto.
