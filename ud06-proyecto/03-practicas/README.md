# UD6 — Prácticas y Fases del Proyecto

El desarrollo práctico de esta unidad se organiza en **5 fases estructuradas** a lo largo de 5 semanas. El guión técnico detallado con las actividades presenciales, el trabajo autónomo y los entregables de cada hito se encuentra en:

- `../guion_proyecto.md`

### Fases de Trabajo Práctico
- **Fase 0 — Formación y tema (Semana 1)**: Creación de grupos, selección de dominio y fuentes de datos (mínimo 2 públicas/reales), planificación técnica inicial.
- **Fase 1 — Ingesta y arquitectura (Semana 2)**: Diseño del diagrama Medallion, creación de capa *Bronze* reproducible mediante scripts, reporte de calidad inicial.
- **Fase 2 — Calidad y procesamiento (Semana 3)**: Transformaciones *Silver → Gold*, aplicación de reglas de validación, checklist de calidad/RGPD y anonimización obligatoria.
- **Fase 3 — Dashboard técnico (Semana 4)**: Construcción de visualizaciones operativas en Metabase para monitorizar caudal, latencia, errores y calidad del pipeline.
- **Fase 4 — Cierre y presentación (Semana 5)**: Elaboración de memoria técnica, repositorio público reproducible, declaración de uso de IA y defensa oral del proyecto.
