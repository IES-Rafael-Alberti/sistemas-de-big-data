entrega y los materiales de partida. No hay una segunda ubicación en evaluación.

Los ZIP son derivados locales para Moodle. El código editable se conserva en las
carpetas de cada práctica.

## Cuestionarios

- `cuestionarios/quiz-ud1.gift`: banco GIFT de conceptos UD1.
- `cuestionarios/quiz-ud1-parte0.gift`: banco GIFT de estadística y matemática.
- `cuestionarios/UD1_P0_Cuestionario_Estadistica_y_Capsula_Normativa.gift`:
  cuestionario matemático completo, con 10 test y 6 ensayos de corrección manual.
- `cuestionarios/UD1_P0_Cuestionario_Estadistica_y_Capsula_Normativa.md`:
  referencia con preguntas, respuestas y criterios de corrección. No subir como
  documento de preguntas al alumnado; su versión importable es el GIFT homónimo.

Los GIFT se importan al banco de preguntas de Moodle para configurar el cuestionario.
No se adjuntan como recursos de descarga.
